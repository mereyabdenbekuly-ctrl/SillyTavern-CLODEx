# CLODEx for SillyTavern · 0.2.0

Standalone UI Extension для **SillyTavern 1.19.0+**. Никаких npm-зависимостей,
сборщика, ComfyUI, серверного плагина или изменений SillyTavern для генерации.
Требуется собственный API-ключ `sk-…` CLODEx и доступ к выбранным моделям.

**Статус: MVP / preview 0.2.0, не полное выполнение исходного ТЗ.**
Реальная установка SillyTavern и платные провайдеры ещё требуют приёмочного теста.
Публикация расширения не включает изменения сайта clodex.xyz или production-деплой.
Платные запросы при разработке не запускались; тесты используют имитацию API.

[English](README.en.md) · [Готовность и ограничения](docs/ROADMAP.md) · [MIT](LICENSE)

## Установка по ссылке

1. В SillyTavern откройте **Extensions → Install Extension**.
2. Вставьте URL репозитория:

   ```text
   https://github.com/mereyabdenbekuly-ctrl/SillyTavern-CLODEx
   ```

3. Подтвердите установку и перезагрузите интерфейс.
4. Откройте **Extensions → CLODEx**, введите ключ, нажмите **Подключить / обновить**,
   выберите модели. Для текстовых ответов нажмите **Использовать в чате**.
5. Откройте чат с персонажем. Кнопки появятся под его сообщениями.

Для цен и валюты может потребоваться настройка публичного прокси, описанная ниже.

### Ручная установка

1. Скопируйте папку `SillyTavern-CLODEx` из ZIP или этой рабочей копии в
   `<SillyTavern>/data/<ваш-профиль>/extensions/SillyTavern-CLODEx`.
   Для профиля по умолчанию: `data/default-user/extensions/SillyTavern-CLODEx`.
   В корне скопированной папки должен находиться `manifest.json`, без дополнительной вложенности.
2. Перезагрузите SillyTavern. Откройте **Extensions → CLODEx**.
3. Введите ключ, нажмите **Подключить / обновить**, выберите модели.
4. Откройте чат с персонажем. Кнопки появятся под его сообщениями.

Установщик SillyTavern делает `git clone`: ссылка на `manifest.json` или ZIP **не является**
URL установки/автообновлений. `auto_update: true` работает у Git-установки.
Не вставляйте URL всего монорепозитория CLODEx.

## Возможности

- Живой каталог `/v1/models`, без вымышленных/зашитых названий. В списках есть
  отдельная группа «Другие модели API»: классификация аудио/медиа по именам — лишь подсказка.
- **Использовать в чате** настраивает штатный **Custom OpenAI**, URL
  `https://clodex.xyz/v1`, модель и ключ в серверном Secrets SillyTavern.
  Переключение требует подтверждения. Пресеты RP, карточки, контекст и стриминг
  остаются под управлением SillyTavern, а не отдельного текстового движка расширения.
  Если у Custom OpenAI остались пользовательские header/body overrides, расширение
  предложит очистить их с отдельным подтверждением. Отмена ничего не меняет.
  Для восстановления прежнего подключения предварительно сохраните его пресет.
- Баланс кошелька владельца ключа в USD/₽ через `/api/usage/token/`, если сервер
  возвращает новые поля `wallet_balance_usd` / `wallet_balance_rub`. Лимит ключа
  показан отдельно: `unlimited_quota` больше не скрывает баланс кошелька.
  Старый сервер явно обозначается как «кошелёк недоступен»; лимит не выдаётся за баланс.
- Публичные справочные цены, вход/выход и чтение кэша (если API их возвращает).
  Групповые тарифы и промо не угадываются; окончательное списание определяет сервер.
- Изображения через `/v1/images/generations`, base64 и HTTPS URL ответа.
- Видео через `/v1/videos`, опрос статуса и локальный прогресс. Image-to-Video
  отправляет байты выбранной/последней картинки как data URL в общем JSON-поле `image` CLODEx.
  Совместимость этого пути и допустимые параметры зависят от модели.
- Видео скачивается через авторизованный `/v1/videos/:id/content` и сохраняется
  в SillyTavern. API-ключ не вставляется в URL плеера. Прогресс без процентов
  отображается как неопределённый; проценты не выдумываются.
- Готовые изображения/видео/аудио сохраняются через `/api/files/upload`, затем
  добавляются в `message.extra.media`. Текст сообщения и прежние вложения сохраняются.
- Озвучка кнопкой или `/clodex-say` через `/v1/audio/speech`; распознавание
  аудиофайла через `/v1/audio/transcriptions`. STT **не отправляет** распознанное сообщение.
  Это собственные controls расширения, не провайдер встроенной вкладки TTS; записи микрофона нет.
- Опциональные `clodex_generate_image` и `clodex_generate_video` через
  `registerFunctionTool`. Требуются поддержка Tool Calling моделью и его включение
  в подключении SillyTavern. Результат прикрепляется к последней реплике персонажа;
  каждый вызов инструмента отдельно подтверждается пользователем.
- RU/EN, адаптивная панель и настройки автопроигрывания/цикла видео.

## CORS и совместимость бэкенда

**При публикации 0.2.0 серверный патч ещё не развёрнут:** прямой доступ к
метаданным и реальный баланс на clodex.xyz пока остаются заблокированы.
Подробности и границы проверки — в [CHANGELOG.md](CHANGELOG.md).

Расширение обращается напрямую к `/api/pricing`, `/api/status` и `/api/usage/token/`.
Для первого подключения без изменения `config.yaml` на бэкенде должен быть выпущен
патч CORS: `Access-Control-Allow-Origin: *`, только `GET, OPTIONS` для этих точных
маршрутов, без `Access-Control-Allow-Credentials`. Кошелёк требует Bearer API-ключ;
сессионные и административные API этим правилом не открываются.

**Публикация расширения сама по себе не обновляет сервер CLODEx.** Если сервер ещё
не получил патч или сеть недоступна, UI объясняет отсутствие данных. Новый эндпоинт
ключа возвращает баланс, `quota_per_unit` и явный `usd_to_rub`, поэтому для вывода
кошелька не требуется отдельный успешный запрос `/api/status`. Неограниченный ключ
не означает бесконечный баланс или бесплатные генерации.

Старый необязательный переключатель публичного прокси оставлен только для
совместимости. Для него нужны `enableCorsProxy: true` и перезапуск **локального
защищённого** SillyTavern; включать его после серверного исправления не нужно.
Он передаёт только два публичных GET (`status`, `pricing`), никогда ключ CLODEx,
и **не исправляет** закрытый CORS защищённого `/api/usage/token/` старого сервера.

RUB показывается только при явном рублёвом поле/курсе сервера, без зашитого курса.

## Команды

```text
/clodex-img
/clodex-img A cinematic portrait in a moonlit forest
/clodex-img message=4 A rainy street scene
/clodex-video A slow cinematic camera move
/clodex-video message=4 animate=true Wind moves the character's hair
/clodex-say
/clodex-say message=4 Hello there
/clodex-resume message=4
/clodex-cancel
```

`message` — нулевой индекс существующей реплики персонажа. Без него используется
последняя реплика персонажа. Явный промпт не вызывает дополнительную текстовую генерацию.
Пустой промпт использует карточку и до четырёх последних сообщений; опция
`generateQuietPrompt` дополнительно обращается к активному текстовому провайдеру
SillyTavern с его полным настроенным контекстом. В групповом чате карточка выбирается
по `original_avatar` автора сообщения.

## Расходы, ключи и восстановление

- **Запомнить ключ в SillyTavern** включено по умолчанию. После ввода ключа и
  подключения он сохраняется в `extensionSettings.clodex.savedKey` вашего профиля,
  восстанавливается после F5, а каталог/баланс обновляются автоматически.
  **Хранилище незашифрованное**: ключ доступен серверу, установленным расширениям
  и попадает в резервные копии настроек. Используйте защищённый доверенный сервер.
  Для публичного/общего сервера отключите галочку до подключения: сохранённый ключ
  удаляется, текущая вкладка продолжает работать, а после F5 нужен повторный ввод.
  Ключ не записывается в сообщения/экспорт чата, localStorage, sessionStorage или ZIP.
  Настройка `allowKeysExposure` не включается: native Secrets не раскрываются.
- **Использовать в чате** отдельно сохраняет ключ в штатном серверном Secrets.
  **Забыть сохранённый ключ** удаляет ключ расширения из профиля и памяти вкладки,
  но не удаляет этот отдельный серверный секрет; удалить его нужно в SillyTavern.
- Автоиллюстрации и инструменты выключены по умолчанию. Автоиллюстрации требуют
  отдельного согласия, ограничены одной в минуту и одной попыткой на сообщение,
  включая неуспешную попытку. Инструменты всегда спрашивают подтверждение.
- Серверные POST создания **никогда не повторяются автоматически**. Повторяются
  только безопасные GET статуса, ограниченно, при 429/502/503/504.
- Кнопка остановки отменяет локальное ожидание/скачивание. Уже принятая сервером
  генерация может завершиться и тарифицироваться; отмена не обещает возврат денег.
- ID видеозадачи сохраняется до опроса. После таймаута, перезагрузки или сбоя
  скачивания нажмите **Продолжить без новой задачи**. В режиме без запоминания
  сначала повторно введите ключ и подключитесь.
- Если соединение оборвалось **до получения ID**, результат отправки неизвестен.
  Проверьте историю CLODEx перед повторной генерацией. Для изображений и речи
  после неопределённого исхода автоматического повтора также нет.
- Смена чата, свайпа, удаление/редактирование сообщения отменяет локальную работу.
  Асинхронный результат не вставляется в другой чат или изменённую реплику.
- Медиа хранятся на сервере SillyTavern: JSON-экспорт чата сам по себе не включает
  бинарные файлы. Делайте резервную копию `user/files` вместе с чатами.
- Локальный лимит медиа — 100 МБ, входа Image-to-Video — 20 МБ, STT — 25 МБ.
  Ограничения провайдера/прокси/SillyTavern могут быть ниже.
- Промо-видео применяются только сервером при доступности для этого ключа.
  Расширение не обходит правила провайдеров и не обещает бесплатные генерации.

## Разработка и упаковка

Node.js 20+ нужен только разработчику; установка зависимостей не требуется.

```sh
npm test
npm run check
npm run package
node tests/browser-server.mjs
```

Последняя команда поднимает изолированный браузерный стенд на localhost с
фиктивным ключом и моками API; реальных списаний нет. ZIP создаётся в `dist/`
из явного белого списка файлов. Для проверки в настоящем SillyTavern сначала
проверьте подключение без генераций, затем выполните одну оплачиваемую генерацию
выбранной модели с согласия владельца ключа.

Контракты и источники исследования: [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

Лицензия кода: [MIT](LICENSE). Лицензия не предоставляет доступ к платному API;
доступность моделей, лимиты и тарификация определяются CLODEx и провайдерами.
